## Response Section

### ความแตกต่าง
#### JSON
- เป็๋นรูปแบบข้อความ
- มีขนาดใหญ่เนื่องจากต้องส่ง Key เป็นข้อความทุกครั้ง

#### Protocol Buffer
- เป็นรูปแบบ Binary
- มีขนาดเล็กเพราะใช้ตัวเลขแทน Key
- มีความเร็วในการทำงานเนื่องจากทำงานในระกับ Binary

### JSON
#### ข้อดี
- อ่านง่าย นักพัฒนาสามารถอ่าน ตรวจสอบ และดีบักข้อมูลได้ทันทีโดยไม่ต้องใช้เครื่องมือพิเศษ
- ไม่ต้องกำหนดโครงสร้างข้อมูล สามารถเพิ่มหรือลดฟิลด์ได้ตามต้องการ
#### ข้อเสีย
- ขนาดไฟล์ใหญ่เพราะมีตัวอักษร
- ประมวลผลช้าเนื่องจากการแปลงข้อความให้กลายเป็น Object ในหน่วยความจำ (Deserialization) ใช้ทรัพยากรและเวลามากกว่า
- ไม่มีการบังคับ Type ชนิดของข้อมูล

### Protocal Buffer
#### ข้อดี
- ขนาด Payload เล็กมาก ประมวลผลไว
- มีการกำหนดบังคับชนิดข้อมูลชัดเจน ช่วยลดข้อผิดพลาดที่เกิดจากการส่งข้อมูลผิดประเภท
#### ข้อเสีย
- ทำการ Debug ได้ยาก ต้องใช้ tool หรือเขียน code เพื่อแปลง Binary เป็นข้อความก่อน
- ความซับซ้อนในการพัฒนา
